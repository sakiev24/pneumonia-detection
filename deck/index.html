The problem we picked

The task

Look at one chest X-ray and answer: normal or pneumonia. Doctors read thousands of these, and a second opinion that never gets tired is useful.

Why a CNN fits

Pneumonia shows up as local patterns: hazy white patches. Convolution filters learn such patterns straight from the pixels, and pooling makes them hold up when the patient stands a bit to the left. Nobody has to hand-design features.

Why we care about recall

Sending home a sick patient is far worse than a false alarm. So next to accuracy we report recall for each class: how many sick patients the model actually finds.

12,024 X-rays, half of them sick

Adult chest X-rays from the RSNA Pneumonia Detection Challenge, labelled by radiologists. We take them from the COVID-19 Radiography Database on Kaggle (299×299 PNG) and shrink them to 128×128.

normalpneumoniasplit 70 / 15 / 15, stratified, fixed seed

Pneumonia: all 6,012 Lung Opacity images.

Normal: 6,012 images drawn with a fixed seed from the 8,851 RSNA normals, so the classes are exactly balanced.

we only use RSNA images. If the two classes came from different hospitals, the CNN could learn to spot the hospital instead of the disease!

Preprocessing: every image gets the same treatment

  1. Grayscale, crop, resize

    Convert to one gray channel, cut the centre square and resize to 128×128 pixels. New images in predict.py go through exactly the same function.

  2. Scale to 0–1

    Pixel values 0–255 are divided by 255, which keeps the numbers small for training.

  3. Augment, training images only

    Random rotation up to ±10°, shift up to ±5%, zoom up to ±5%. Every epoch the model sees a slightly different version, which fights overfitting.

  4. No mirror flips

    Left and right matter in a chest: the heart sits on the left. A flipped X-ray is not a realistic patient.

Both classes are 50/50, so plain cross-entropy loss is enough, and accuracy means something: a lazy model that always says “pneumonia” would only get 50%.

Save once, reload anywhere

# model.py
def save_model(model):
    torch.save(model.state_dict(), MODEL_PATH)

def load_model():
    model = PneumoniaCNN()
    model.load_state_dict(torch.load(MODEL_PATH,
                          map_location="cpu", weights_only=True))
    return model.eval()
